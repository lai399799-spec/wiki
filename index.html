UNIT 00 · CURRICULUM OVERVIEW

生成式 AI 在前端網頁
自動化開發的應用

把你的工作拆成 AI 能做的流程：從知識庫到互動式單頁簡報

在 AI 代理（AI Agent）時代，初學者不需要手刻每一行繁瑣的 CSS 與 HTML，而是學習當一位「懂流程的專案設計師」。透過明確的視覺規範、結構化的 Markdown 知識庫，以及帶有自我檢查機制的自動化工作流，你就能指揮 Code Agent 穩定產出高品質的前端教學簡報。

講義拾號
核心公式
AI Agent ＝ AI 模型（大腦）＋ Harness（工作規範與檢核流程）
不要讓 AI 靠猜的做事——把「可修改範圍、命名規則、驗收標準」寫成規格書，這就是前端自動化的起點。

UNIT 01 · VISUAL CONSTITUTION

Design Tokens 與 CSS 樣式規範

用「具名設計變數」代替模糊形容詞，讓 AI 產出的每一頁風格都完全統一

壹之章

為什麼「日系簡約風」不能只靠嘴巴說？

如果你只對 AI 下指令：「幫我做一個可愛或文青的簡報」，AI 每次都會自己猜顏色與字型，第一頁用粉紅、第三頁變成亮藍，這在團隊或跨頁面製作時稱為「風格漂移」。

解法：先把顏色、字體、間距定義成 CSS 變數（Design Tokens），再寫進 AGENTS.md 憲法中。

初學者必懂的三層 Token 分工

1. 底紙與容器層：--background（宣紙底色）與 --surface-container-low（和紙卡片）。

2. 墨水與層級層：--on-surface（主文炭墨）與 --on-surface-variant（次要說明）。

3. 視覺訊號層：--secondary（苔蘚綠小標）與 --tertiary（硃砂印泥重點，全頁不超過 2%）。

互動展示：Design Token 即時換裝實驗室

LIVE CSS VARIABLES
THEME: WASHI LINEN --rounded: 2px
AI 自動生成的講義卡片預覽 無論簡報擴充到第幾頁，只要引用同一份 Token，版面比例與配色就會自動對齊。
--background
--surface-low
--secondary
--tertiary 
:root {
  --background: #f4f1ea;            /* 未漂白亞麻紙 */
  --surface-container-low: #ebe6db; /* 和紙卡片底 */
  --on-surface: #1c1b18;            /* 炭墨主文字 */
  --secondary: #4a5d46;             /* 苔蘚綠標籤 */
  --tertiary: #9e3b2b;              /* 硃砂印泥點綴 */
}
UNIT 02 · ARCHITECTURE

Single-Page Presentation 簡報架構

一份純 HTML 檔如何變身多頁簡報？掌握「狀態管理」與「分頁渲染」原理

貳之章

為什麼自動化簡報偏愛「單一 HTML 檔」？

課程範例中，AI 從知識庫讀取論文並產出一份 HTML 簡報。把結構（HTML）、樣式（CSS）與切換邏輯（JS）合而為一，最大優點是無需架設伺服器、不依賴外部套件，推上 GitHub Pages 後任何裝置一點即開。

背後的三個核心零件

1. 投影片容器（Sections）：每個單元都是一個 <section class="slide">，預設用 CSS display: none 藏起來。

2. 頁碼狀態（State）：JavaScript 用一個變數 currentSlide = 0 記住「讀者現在正在看第幾頁」。

3. 切換函式（Controller）：按下「下一頁」或鍵盤 → 時，移除舊頁的 .is-active，加到新頁上，同時更新進度條。

觀察下方 HTML 節點如何切換顯示狀態：

<section class="slide"> 實戰總結 </section> display: none
UNIT 03 · AGENTIC WORKFLOW

Vibe Coding 與 Code Agent 開發模式

用自然語言當老闆，但把流程拆成「討論憲法、Loop 迴圈與 Graph 檢查點」

參之章
CODE AGENT VS CHATBOT

為什麼需要 Code Agent？

一般聊天機器人只能複製貼上；Code Agent（如 Antigravity、Claude Code）能直接讀寫你的專案資料夾、操作終端機預覽，還能用 Git 版本控制把每次修改存成歷史紀錄——做壞了隨時退回上一版。

PROJECT CONSTITUTION

先寫 AGENTS.md 再開工

開新對話視窗時，AI 會忘記之前說過的話。把「資料夾規定、語言風格、哪些檔案不能動」寫進 AGENTS.md（員工手冊），就能確保每次開工都維持一致品質並節省 Token。

BRAKE & HUMAN GATE

人類檢查點要放在「大綱」

不要等 AI 寫完幾千行 HTML 才來逐頁硬改！把人類審核放在「簡報大綱」階段最省力；後面的排版與錯誤修正，交給 AI 自己的迴圈加上「最多重試 3 次」停損點即可。

UNIT 04 · CONTENT PIPELINE

Markdown 轉 HTML 渲染機制

用純文字寫內容、交給程式變網頁：LLM Wiki 與教學講義的共同語言

肆之章

為什麼大家都在寫 .md 檔？

Markdown 用極簡符號標記結構（# 是標題、- 是清單、`程式` 是行內代碼）。比起塞滿 <div> 的 HTML，Markdown 人類看得懂、AI 也不容易寫錯標籤，是 AGENTS.md 與 LLM Wiki 知識庫的標準格式。

轉換三步驟：讀檔 → 解析 → 套版

Step 1 讀取純文字：程式逐行讀取 .md 檔案內容。
Step 2 語法解析（Parse）：比對開頭符號，把 # 標題 換成 <h1>標題</h1>，把 [[連結]] 轉為知識跳轉標籤。
Step 3 套用樣式：瀏覽器依照 Unit 01 的 CSS Token 上色排版，講義立即誕生。
