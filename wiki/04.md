# Markdown 轉 HTML 渲染機制

## 核心定義
將純文字 Markdown 大綱自動轉化為具備結構化 HTML 標籤與 CSS 卡片樣式的自動化編譯流程。

## 關鍵機制
- **AST 解析**：將 Markdown 的 Heading, List 轉為 JSON 語意樹。
- **HTML 範本套用**：結合 [[02_Single_Page_Presentation架構]] 將內容塞入 `<section>` 簡報頁。
- **Token 控制**：在 [[03_Vibe_Coding_Code_Agent開發模式]] 下，分階段生成大綱與內文以節省 Token。
