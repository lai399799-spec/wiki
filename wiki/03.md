# Vibe Coding 與 Code Agent 開發模式

## 核心定義
Vibe Coding 是一種透過自然語言與 AI Code Agent (如 Cursor, Antigravity, Claude Code) 進行高階協作的網頁開發模式。

## 關鍵機制
- **先討論後生成**：開發前先透過對話定義專案規範檔（如 agent.md）。
- ** Context 供給**：引導 Agent 讀取 [[04_Markdown轉HTML渲染機制]]，避免 AI 自由發揮導致代碼失控。
- **自動化維護**：結合 [[05_自動化語法與路徑檢查]] 進行錯誤自我修復。
