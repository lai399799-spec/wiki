# Single-Page HTML 簡報架構

## 核心定義
Single-Page Presentation (SPA 簡報) 將整份簡報封裝於單一 HTML 檔案中，透過 JavaScript 監聽鍵盤事件實現流暢切換。

## 關鍵機制
- **DOM 結構**：以 `<section class="slide">` 為基本頁面單位。
- **切換邏輯**：使用 CSS class `active` 搭配 `opacity` 與 `transform` 實現過渡效果。
- **樣式注入**：依據 [[01_Design_Tokens_CSS樣式規範]] 進行排版。
